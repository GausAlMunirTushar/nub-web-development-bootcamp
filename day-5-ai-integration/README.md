# Day 5 — AI Vibe Coding and Integration

Day 5 teaches how to use AI coding agents safely and effectively. Students
practice prompt engineering, code inspection, debugging and feature
verification.

## Live Coding Prompt

```text
Build a simple project management website using Next.js.

Requirements:
1. Create a responsive navbar.
2. Create a dashboard.
3. Add a project creation form.
4. Display projects in a table.
5. Allow users to edit and delete projects.
6. Use reusable React components.
7. Explain the folder structure.
8. Explain how the application works.

Do not just generate code.
Explain the purpose of each major file.
```

## Working with AI-Generated Code

Always:

- Read the prompt requirements carefully
- Ask the AI to explain unfamiliar code
- Find every file the AI changed
- Read the complete error message
- Run the application after each change
- Test the feature in the browser
- Review generated code for unrelated or risky changes
- Modify code instead of blindly copying it

## Verification Checklist

- The application starts without errors
- The responsive navbar works
- The dashboard displays correctly
- The project form creates an item
- Projects are displayed in the table
- Edit updates the selected project
- Delete removes the selected project
- The file structure follows Next.js conventions
- Major components and files can be explained
