# Day 1 — HTML, CSS and JavaScript

This practical introduces website structure, visual styling and browser
interactions using a CampusConnect registration and landing page.

## 60-Minute Schedule

| Time | Topic |
|---|---|
| 0–10 minutes | Website basics and frontend vs backend |
| 10–20 minutes | HTML structure, inputs and forms |
| 20–30 minutes | CSS, Flexbox and responsive layout |
| 30–40 minutes | JavaScript variables, functions and events |
| 40–55 minutes | Live coding: registration page |
| 55–60 minutes | Quick quiz and questions |

## Implemented Features

- Responsive landing page
- Navigation and call-to-action
- CampusConnect hero and project cards
- Registration form
- Required-field and format validation
- JavaScript submission feedback

## Project Files

| File | Purpose |
|---|---|
| `index.html` | Page structure and semantic content |
| `styles.css` | Layout, visual design and responsive rules |
| `script.js` | Validation and form event handling |

## Run the Project

Open `index.html` directly, or start a local server:

```powershell
cd day-1-web-basics
python -m http.server 4173
```

Open `http://localhost:4173`.

## Homework

Create a landing page for a startup of your choice. Include:

- A startup name and short description
- Navigation links
- One or more call-to-action buttons
- Responsive layout
- A JavaScript interaction
- Optional registration or contact form

## Learning Outcomes

After completing this day, you should be able to:

- Explain frontend and backend responsibilities
- Create semantic HTML
- Build layouts with CSS and Flexbox
- Add responsive styles
- Handle browser events
- Read and validate form input
