# Day 1 — HTML, CSS and JavaScript

Day 1 introduces the basic parts of a website and the difference between
frontend and backend. The class uses a simple CampusConnect registration
page to demonstrate how HTML creates structure, CSS creates design and
JavaScript creates behavior.

## 60-Minute Schedule

| Time | Topic |
|---|---|
| 0–10 minutes | What is a website? Frontend vs backend |
| 10–20 minutes | HTML headings, forms, buttons and inputs |
| 20–30 minutes | CSS colors, layout, Flexbox and responsive design |
| 30–40 minutes | JavaScript variables, functions, conditions and events |
| 40–55 minutes | Live coding: Registration page |
| 55–60 minutes | Quick quiz and questions |

## Core Goal

Understand how a website works:

- HTML = structure
- CSS = design
- JavaScript = logic

## Live Coding — Registration Page

The registration page collects the following information:

- Name
- Email
- Department

It also contains a Submit button. When the form is submitted, JavaScript
reads the entered values and displays the submitted information.

## Files

| File | Purpose |
|---|---|
| `index.html` | Defines the page content and registration form |
| `styles.css` | Controls layout, colors, typography and responsive design |
| `script.js` | Handles form submission and displays the submitted values |

## Features

- Responsive landing page
- Desktop and mobile navigation
- CampusConnect hero section
- Project preview cards
- Feature section
- About section
- Registration form
- Form validation
- JavaScript event handling
- Submitted data display

## Run the Project

Open `index.html` directly in a browser.

You can also start a local server from this folder:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Homework

Create a simple landing page for your startup.

The landing page should use HTML, CSS and JavaScript and should include:

- A clear startup name
- A heading and short description
- Navigation links
- At least one call-to-action
- Responsive layout
- At least one interactive JavaScript feature

## Learning Outcomes

After completing Day 1, you should be able to explain:

- What the frontend is
- What the backend is
- How HTML elements are structured
- How CSS controls appearance and layout
- How JavaScript responds to an event
- How form input is read and displayed
